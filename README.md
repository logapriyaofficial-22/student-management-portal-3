# Student Management Portal

## Project Description
The Student Management Portal is a web-based application designed to manage student information efficiently.

## Objectives
- To maintain student records.
- To provide course information.
- To simplify student registration.
- To organize student details.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub

## Modules
1. Home
2. About
3. Student Registration
4. Courses
5. Contact
